# MONO COFFEE ☕

**Концепт современного сайта кофейни.**

🔗 **Демо:** https://brawlakthif-a11y.github.io/mono-coffee/

## О проекте

MONO COFFEE — адаптивный сайт кофейни с минималистичным дизайном, тёплой цветовой палитрой и удобным меню.

## Возможности

- Каталог напитков и десертов
- Поиск и фильтрация товаров
- Корзина с изменением количества товаров
- Демонстрационное оформление заказа
- Адаптивная вёрстка для компьютеров и телефонов

## Технологии

- HTML
- CSS
- JavaScript
- localStorage
- GitHub Pages

## Статус проекта

Учебный демонстрационный проект. Реальная оплата, серверная обработка заказов и доставка не подключены.
